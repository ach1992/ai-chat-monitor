Privacy & data

What Guardian processes

Guardian reads page state and bounded recent visible chat content on supported ChatGPT pages to classify monitored conversations. Full transcripts are not stored. Optional providers receive only minimized, secret-redacted context when fallback classification is needed. Telegram receives bounded notification metadata by default. Guardian never writes to ChatGPT. Read the privacy policy.

Read-only by design: Guardian observes and notifies; it never sends, retries, or continues ChatGPT turns.
